# BRICK. — Pitch Doc

**Vision:**
I wanted to see if I could sell a plain red brick as a $499 luxury item. Knowing people get bored in seconds, I had to keep them hooked. I designed a "deadpan luxury" page that contrasts minimal aesthetics with high-energy interactive moments, like a cinematic video hero, smooth scroll storytelling, a sticky CSS 3D brick, and a stacking minigame.

**Tools & Prompting Style:**
I built the site using HTML, CSS, and JS. For the AI, I used **Veo 3** for the striking video background, **Nano Banana** for assets, and **Antigravity** to code it. My prompting was strictly step-by-step. Instead of asking for the whole site upfront, I guided Antigravity component-by-component, tweaking intersection observers and game logic until it felt totally seamless.

**Satisfaction:**
I'm thrilled. The site feels super premium but still playful. It proves that if you collaborate closely with AI, you can make a literal rock feel exciting.
